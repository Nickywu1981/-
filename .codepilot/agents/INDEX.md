# G2 统筹组 Agent 索引

> 第二组 — 项目统筹组，不写代码，只管需求/PRD/分派/进度/验收

## Agent 列表

| Agent | 文件 | 职责 |
|-------|------|------|
| Orchestrator | `g2-orchestrator.md` | 任务拆分分派、进度追踪、跨组协调、五维验收、风险预警 |
| Product-Manager | `g2-product-manager.md` | 需求分析→用户故事→PRD→优先级矩阵→验收标准→埋点 |

## 调用方式

在对话中 `@Orchestrator` 或 `@Product-Manager` 即可激活对应角色。

## 约束

- 两个 Agent **禁止写任何代码**
- Product-Manager 只与 Orchestrator 对接，不直接指挥开发组
- 技术方案必须经 G1 Architect 审批
