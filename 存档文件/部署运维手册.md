# 部署与运维手册

## 1. 环境要求

| 组件 | 最低版本 | 说明 |
|------|---------|------|
| Node.js | 18.x | 推荐 20 LTS |
| MySQL | 8.0+ | 需开启 `mysql_native_password` |
| Redis | 6.x+ | 用于缓存 + BullMQ 消息队列 |
| MinIO | 2023+ | 本地对象存储（可选 S3） |
| Nginx | 1.20+ | 反向代理 + 静态资源 |
| PM2 | 5.x+ | Node 进程管理 |

## 2. 环境变量配置

```bash
# server/.env
NODE_ENV=production
PORT=3001

# 数据库
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=movio_ai

# Redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=

# JWT
JWT_SECRET=your_64_char_random_secret
JWT_EXPIRES_IN=7d

# MinIO / S3
STORAGE_ENDPOINT=127.0.0.1
STORAGE_PORT=9000
STORAGE_ACCESS_KEY=minioadmin
STORAGE_SECRET_KEY=minioadmin
STORAGE_BUCKET=movio-assets
STORAGE_USE_SSL=false

# AI API Keys（可选）
OPENAI_API_KEY=sk-xxx
ANTHROPIC_API_KEY=sk-ant-xxx
STABILITY_API_KEY=sk-xxx

# SMS / Email
SMS_PROVIDER=aliyun
SMS_ACCESS_KEY=xxx
EMAIL_HOST=smtp.example.com
EMAIL_USER=noreply@example.com

# 前端
# client/.env
NUXT_PUBLIC_API_BASE=http://localhost:3001
NUXT_PUBLIC_SITE_URL=http://localhost:3000
```

## 3. 数据库初始化

```bash
# 创建数据库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS movio_ai CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 导入表结构
mysql -u root -p movio_ai < server/sql/schema.sql

# 导入种子数据（演示用）
mysql -u root -p movio_ai < server/sql/seed.sql

# 运行迁移（若已有数据库）
cd server && npm run migrate
```

## 4. Docker Compose 部署

```bash
# 启动全部服务
docker-compose up -d

# 查看状态
docker-compose ps

# 查看日志
docker-compose logs -f server
docker-compose logs -f client

# 停止
docker-compose down
```

## 5. 手动生产部署

### 5.1 构建前端

```bash
cd client
npm ci
npm run build
# 产出在 client/.output/
```

### 5.2 启动后端

```bash
cd server
npm ci --production
npm run start
```

### 5.3 PM2 进程管理

```bash
# 安装 PM2
npm install -g pm2

# 启动
pm2 start ecosystem.config.js

# 常用命令
pm2 status          # 查看状态
pm2 logs movio-api  # 查看日志
pm2 restart all     # 重启全部
pm2 save            # 保存进程列表
pm2 startup         # 开机自启
```

### 5.4 Nginx 配置

```nginx
# /etc/nginx/sites-available/movio-ai
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态资源
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 后端 API
    location /api/ {
        proxy_pass http://127.0.0.1:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # WebSocket
    location /ws {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # 上传文件
    client_max_body_size 100M;
}
```

## 8. 监控与告警

- **PM2 指标**：`pm2 monit` 实时监控 CPU/内存
- **Winston 日志**：`server/logs/error.log` + `server/logs/combined.log`
- **健康检查**：配置 Uptime Kuma 或 Grafana 监控 `/api/health`
- **日志采样**：错误 100%，普通 10%，健康检查 1%

## 9. 回滚预案

触发条件：接口 500 率 > 5% / 页面白屏 / 数据库迁移失败 / 内存持续增长

回滚步骤：
1. `pm2 stop movio-api`
2. `git checkout <last-stable-tag>`
3. `cd server && npm ci --production`
4. 回滚数据库迁移（如需要）
5. `pm2 start movio-api`

## 10. Redis 持久化

生产环境需开启 AOF + RDB 双写：

```conf
# docker/redis-persistence.conf
appendonly yes
appendfsync everysec
save 900 1
save 300 10
save 60 10000
maxmemory 2gb
maxmemory-policy allkeys-lru
```
