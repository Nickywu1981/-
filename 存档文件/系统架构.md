## 数据流

```
用户输入 → intentRouter 解析意图 → 路由到功能页
→ PromptEnhancer 增强提示词 → $fetch 调用 API
→ authMiddleware 验证 JWT → Zod validate 校验入参
→ Controller → Service（业务逻辑）
→ ModelAdapter 选择 AI 模型 → API 调用 → 结果返回
→ BullMQ 异步任务（视频/批量） → WebSocket 推送进度
→ 结果存储 MinIO → WebP 自动转换 → 返回前端
```

## 安全体系

| 层级 | 措施 |
|------|------|
| 传输 | HTTPS + JWT + CSP 安全头 |
| 认证 | bcrypt 密码哈希 + JWT 7天过期 + authLimiter 限流 |
| 入参 | Zod schema 校验（26/32 路由） |
| 限流 | auth(5次/分) + code(1次/分) + global(100次/分) |
| 存储 | MinIO 对象存储 + 预签名 URL 7天有效期 |
| 日志 | Winston 分级采样（错误100%/普通10%/健康1%） |
| 部署 | PM2 512M 重启阈值 + 错误日志分离 |
