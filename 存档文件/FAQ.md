# Movio AI — 常见问题 FAQ

## 账号与登录

**Q: 如何注册？**
支持手机号+验证码和邮箱+验证码两种方式。访问 `/register` 填写信息即可。

**Q: 忘记密码怎么办？**
访问 `/forgot-password`，通过手机号或邮箱重置密码。

**Q: 支持哪些登录方式？**
手机号+密码 / 邮箱+密码 / 手机验证码快捷登录。

## 功能使用

**Q: 支持哪些 AI 图片功能？**
智能抠图、白底图、场景生成、图片精修、虚拟试穿、颜色变换、风格迁移、幽灵模特、智能扩图、去皱、图片翻译、全景图合成等 12+ 功能。

**Q: 支持哪些 AI 视频功能？**
图片转视频、多图合成视频、脚本生成、智能分镜、爆款复刻、视频编辑、AI 配音、数字人播报等 8+ 功能。

**Q: 批量处理怎么用？**
访问工作台 → 批量处理，拖入多张图片选择操作类型（抠图/白底/场景/视频），后台异步处理并 WebSocket 实时推送进度。

**Q: 支持哪些电商平台？**
淘宝、京东、拼多多、抖音、快手、小红书、Shopee、Lazada、Amazon、eBay、TikTok Shop、Instagram Shopping、独立站等 13 个平台专属详情页模板。

## 技术问题

**Q: 图片上传支持哪些格式？**
JPG、PNG、WEBP、GIF，单张最大 20MB。上传后自动转为 WebP 格式。

**Q: 生成结果不满意怎么办？**
支持重新生成、参数调整（风格/光照/构图）。也可使用提示词增强器自动补全参数。

**Q: 处理速度慢怎么办？**
视频和批量任务为异步处理。大图建议不超过 4096px。生产环境建议启用 Redis + BullMQ 队列。

## 积分与付费

**Q: 积分怎么获取？**
每日签到（连续签到递增 2→8）、分享作品、邀请好友、每日赠送。管理员可在后台配置积分策略。

**Q: 有哪些会员等级？**
免费版（基础功能限量）、普通版（每日 50 次）、高级版（无限生成 + API 接入）。

**Q: 如何充值？**
访问 `账号 → 充值`，支持微信/支付宝（沙箱模式，生产需真实商户号）。

## 部署运维

**Q: 最低配置要求？**
Node.js 18+ / MySQL 8.0 / Redis 7 / 2GB 内存 / 10GB 磁盘。Docker Compose 一键启动。

**Q: 支持集群部署吗？**
支持。PM2 Cluster 模式 + Nginx 负载均衡，详见 `存档文件/部署运维手册.md`。

**Q: 如何更新？**
`git pull` → `npm ci` → `npx pm2 restart ecosystem.config.js`。数据库迁移用 `npm run migrate`。

**Q: 支持 HTTPS 吗？**
Nginx 配置 SSL 证书后即可。`nginx.conf` 中取消注释 SSL 相关配置并填入证书路径。

## AI 模型

**Q: 使用哪些 AI 模型？**
支持 OpenAI GPT-4o（文案/理解）、Claude Opus 4（复杂推理）、Stable Diffusion（图片生成）。通过 ModelAdapter 层可切换，配置 API Key 在 `.env`。

**Q: 没有 API Key 能用吗？**
开发模式下 Mock 实现返回示例结果。所有功能可预览但生成结果非真实图片。

**Q: 提示词怎么优化？**
使用工作台智能输入框可自动检测意图并补全提示词参数。模板市场有 6 大类 30+ 预设模板可直接使用。
