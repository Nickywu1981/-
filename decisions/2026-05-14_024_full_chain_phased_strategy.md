# Decision 024 — 全链路分阶段战略：当前聚焦图片/视频，后期模块按序补全

**日期**：2026-05-14  
**影响等级**：🚀 战略级  
**决策者**：G2 统筹组（Orchestrator + Product-Manager）

---

## 背景

项目全维度审计（14 维度）完成后，发现智能体/工作流/RPA/Python/龙虾/画布 6 个模块各有部分基建代码，但核心业务功能大多未开发。需要明确：哪些当前做、哪些延后做、延后顺序。

---

## 决策

### 长期愿景

**电商全链路**为最终目标。工作流、RPA、Python 数据挖掘、智能体为后期刚需模块，龙虾调度为终极功能，画布为可选增强。

### 当前阶段（Phase 2 — 图片/视频聚焦）

**只做**：

| 模块 | 范围 | 说明 |
|------|------|------|
| **工作流** | 仅图片/视频所需 5 条线性基础流程 | white_bg_full、batch_image_expand、detail_page_full、video_generation、viral_clone |
| **智能体** | 保留现有 ADK 地基 | 框架 + 10 Agent + 编排层，不扩展 G3-G6，不开发 tools |
| **RPA** | 保留现有 CRUD 壳 | 任务/账户 MySQL 持久化，不开发真实浏览器自动化 |
| **Python** | 保留零状态 | 无自有代码，不新建 |
| **龙虾调度** | **全程暂不开发** | 仅保留架构预留概念 |
| **画布** | **全程暂不开发** | 现有 DIY 编辑器 + WorkPipeline 正常维护，B1/B3 冻结 |

**不做**：
- 工作流：文本/音频工作流冻结（copywriting_script、voice_audio）
- 工作流：可视化编辑器、条件分支、BullMQ 迁移
- 智能体：G3-G6 角色、tools 目录、Agent 面板
- RPA：Puppeteer/Playwright/Selenium 自动化
- 画布：B1 组件标准化地基、B3 画布集成层

### 后期分阶段补全顺序

```
Phase 3 → Python 数据挖掘（商品数据抓取/竞品分析/价格监控）
  ↓
Phase 4 → RPA（电商平台自动化操作：上架/发货/回复评价）
  ↓
Phase 5 → 智能体（G3-G6 角色 + tools + 全链路 Agent 编排）
  ↓
Phase 6 → 龙虾调度（分布式全链路自动化工厂）
  ↓
Phase 7 → 画布（可选：可视化拼装全链路工作流）
```

### 各阶段触发条件

| 阶段 | 触发条件 |
|------|------|
| Phase 3 Python | 图片/视频模块稳定，日均用户 > 100 |
| Phase 4 RPA | Python 数据挖掘上线，商户反馈需要自动化操作 |
| Phase 5 智能体 | RPA 稳定，需要 Agent 自主决策替代人工配置 |
| Phase 6 龙虾 | 全链路 4 模块就绪，需要统一调度编排 |
| Phase 7 画布 | 前面全部稳定，作为可选体验增强 |

---

## 影响

### 立即生效

- 画布 Decision 022/023 中的 B1/B3/B5+ 任务**全部冻结**
- 工作流只维护 5 条图片/视频流程，其余 2 条冻结
- 智能体/RPA 只做 bug 修复，不接受功能需求

### 资源释放

- 画布 B1+B3 原计划 4 周资源释放给图片/视频模块
- G4 Frontend-A 不再承担画布任务

### 代码保留

- 智能体 ADK 框架（24 文件）继续维护
- RPA CRUD 路由继续保留
- 画布 DIY 编辑器 + WorkPipeline 继续运行
- 龙虾占位页面可移除
