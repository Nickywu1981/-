## 一、安全验收（P0 — 一项不过不得上线）

| # | 检查项 | 标准 | 结果 |
|:--:|------|------|:--:|
| 1.1 | JWT 黑名单 | 登出后 token 立即失效，不可再访问任何需认证接口 | ⬜ |
| 1.2 | 多租户隔离 | 用户 A 无法访问用户 B 的数据（图片/素材/订单/DIY页面/表单） | ⬜ |
| 1.3 | API-Key 加密 | 数据库中 `proxy_configs.api_key` 必须为 AES-256-GCM 密文，前端永远不可见明文 | ⬜ |
| 1.4 | CSRF 防护 | 非白名单 Origin 请求被拒（返回 403） | ⬜ |
| 1.5 | 限流生效 | 单 IP 超过 200次/分钟 返回 429（观察响应头 `X-RateLimit-*`） | ⬜ |
| 1.6 | 入参校验 | 所有路由 Zod schema 覆盖，非法参数返回 400（含具体字段错误信息） | ⬜ |
| 1.7 | 文件上传 | 仅允许 jpg/png/webp/gif/mp4，最大 10MB，非法类型返回 400 | ⬜ |
| 1.8 | SQL 注入 | 所有查询走参数化 DAO，禁止字符串拼接 SQL | ⬜ |
| 1.9 | 密码安全 | bcrypt 哈希存储，无明文密码 | ⬜ |
