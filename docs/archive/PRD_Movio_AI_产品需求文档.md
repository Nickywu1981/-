# Movio AI 产品需求文档 (PRD)

> **版本**: 2.0  
> **日期**: 2026-05-08  
> **范围**: 聚焦 AI 图片 + 视频 + 文案 + DIY 页面编辑器  
> **策略**: 先做真、做精、做到能卖钱，再扩展

---

## 1. 产品概述

| 维度 | 内容 |
|------|------|
| 产品名称 | Movio AI |
| 产品定位 | 电商 AI 视觉 + 文案 SaaS，基于第三方多模型接入架构 |
| 核心价值 | 卖家从"拍图→修图→写文案→做页面→上架"全流程 AI 化 |
| 目标场景 | 国内电商（淘宝/京东/拼多多/抖音）、跨境货架电商（Amazon/Shopee/Lazada）、跨境内容电商（TikTok Shop）、自媒体带货 |
| 三端覆盖 | PC 管理后台 + H5 移动端 + PWA |

**核心差异化能力**: 不光生成图片，还能用拖拽编辑器把 AI 图搭成商品展示页，一键发布。

---

## 2. 用户画像

| 角色 | 痛点 | 核心需求 |
|------|------|------|
| **电商卖家** | 拍照修图费时、写文案没灵感、各平台尺寸不同反复改图 | AI 主图+场景图一键生成、平台尺寸自动适配、标题卖点文案批量产出 |
| **运营人员** | 管理多家店铺，频繁做活动页/商品详情页，不会写代码但需要快速上线页面 | **拖拽编辑器零代码搭建页面、模板库一键套用、PC/手机端预览** |
| **系统管理员** | 管理套餐、审核内容、监控用量 | 管理后台全功能 CRUD |

## 3. P0 核心功能（图片 + 文案）

### 3.1 图片模块

| 功能 | 说明 | 输入 | 输出 |
|------|------|------|------|
| **AI 智能抠图** | 上传商品图，3 秒完成主体识别与背景去除，支持头发级精细分割 | 商品照片 | 透明背景 PNG |
| **AI 白底图** | 抠图后生成纯白/象牙白/冷白背景，支持阴影/倒影效果 | 抠图结果 | 白底商品图 |
| **AI 场景图生成** | 选择预设场景（客厅/海滩/办公桌等）或用文字描述，将商品融入真实场景 | 商品图 + 场景选择/Prompt | 场景融合图 |
| **AI 电商主图生成** | 基于平台规范生成标准主图，自动适配尺寸/格式/白底要求 | 商品图 + 选择平台 | 平台标准主图 |
| **13 平台尺寸一键适配** | 预设淘宝/京东/拼多多/抖音/Amazon/Shopee 等 13 个平台主图+详情图尺寸规范，一键批量适配 | 已生成图片 | 多尺寸输出包 |
| **批量处理** | 一次上传最多 50 张，统一设置抠图+白底+尺寸，一键批量+导出 ZIP | 图片批量上传 | ZIP 下载包 |
| **图片对比/AB测试** | 原图 vs 生成图并排查看、滑动对比、叠图对比、多风格网格排列 | 生成结果 | 对比视图 |

### 3.2 文案模块

| 功能 | 说明 | 输入 | 输出 |
|------|------|------|------|
| **商品标题生成** | 选择平台（淘宝/抖音/Amazon 等），输入商品关键词，AI 生成符合该平台规则的标题（长度/禁用词/SEO 优化） | 关键词 + 平台 | 多标题候选 |
| **卖点文案生成** | 输入商品信息，AI 生成详情页卖点文案（痛点→解决方案→产品优势→行动号召） | 商品信息 | 结构化卖点文案 |
| **跨境翻译+本地化** | 9 语种翻译，不是直译是电商话术本地化（文化适配+口语化+搜索习惯） | 中文文案 + 目标语种 | 本地化文案 |
| **短视频脚本生成** | 选择平台（抖音/视频号/TikTok），输入商品信息，AI 生成差异化脚本结构（开头钩子→痛点→产品展示→成交主张→引导关注） | 商品信息 + 平台 | 口播脚本 |

### 3.3 视频模块

| 功能 | 说明 | 输入 | 输出 |
|------|------|------|------|
| **图片转短视频** | 上传多张商品图，AI 自动生成 15-30 秒短视频（转场+配乐+字幕） | 商品图 3-10 张 | MP4 视频 |
| **商品展示视频** | 单张商品图生成旋转展示/场景动态视频 | 商品图 | MP4 视频 |

## 4. P1 延伸功能（DIY 页面 + 提示词增强）

### 4.1 DIY 页面管理系统（运营人员友好）

> **核心原则**: 运营人员不会写代码，所有操作零代码完成。

| 功能 | 说明 |
|------|------|
| **模板库** | 预置 20+ 行业模板（女装/3C/美妆/家居/食品），运营人员选模板即开始，不需要从零搭建 |
| **页面状态机** | 草稿 → 待审核 → 已发布 → 已下线 → 回收站，状态流转有权限管控 |
| **PC/移动端双端配置** | 同一页面分别配置 PC 端和移动端布局，访问时自适应渲染 |
| **发布前自动校验** | 组件配置合法 + 无敏感词 + 图片已上传 OSS，校验不通过禁止发布 |
| **页面预览** | 编辑中随时预览 PC/手机端效果，支持扫码在手机上真机预览 |
| **版本管理** | 自动快照 + 手动版本，可对比差异、一键回滚 |
| **一键上架/下架** | 一个按钮完成发布或下线，无需登录服务器或改配置 |
| **批量操作** | 批量复制/批量下线/批量删除，运营人员管理大量活动页 |
| **访问统计** | 每个页面的 PV/UV/访问时长，运营人员知道哪个页面效果好 |
| **权限控制** | 编辑者（做页面）和发布者（审核上线）角色分离 |

### 4.2 拖拽可视化编辑器（运营人员友好）

> **核心原则**: 所见即所得，拖进来就能用，不写一行代码。

| 功能 | 说明 |
|------|------|
| **组件拖拽** | 从左侧组件库拖拽组件到画布，松手即定位，实时预览效果 |
| **画布辅助** | 网格线 + 标尺 + 磁吸对齐（5px/10px 可选），组件边缘自动吸附 |
| **电商组件库** | 商品卡片、价格标签、SKU 选择器、库存倒计时、优惠券组件、AI 图片组件、AI 文案组件、倒计时组件 |
| **基础组件库** | 文本、图片、按钮、分割线、轮播图、视频播放器、表单、弹窗 |
| **属性面板** | 点选组件后在右侧表单式编辑属性（非 JSON），文本改字、图片换链接、颜色选色板、尺寸拖滑块 |
| **样式可视化配置** | 边框/圆角/阴影/Hover 效果从下拉框+色板选择，不需要写 CSS |
| **图层管理** | 左侧图层树显示画布所有组件，拖拽调整层级，支持锁定/隐藏/重命名 |
| **撤销/重做** | Ctrl+Z / Ctrl+Y 无限回退，顶部操作栏按钮 |
| **自动保存** | 每 30 秒自动保存到云端，浏览器崩溃可恢复，手动 Ctrl+S 立即保存 |
| **移动端预览** | 一键切换到手机视图，查看移动端布局效果 |
| **操作引导** | 首次使用 overlay 引导（拖一个组件→改属性→预览→发布），5 分钟上手 |

### 4.3 提示词增强体系

| 功能 | 说明 |
|------|------|
| **提示词模板库** | 100+ 电商预设提示词（按品类/风格/平台分类），搜索+筛选 |
| **收藏+自定义分组** | 用户收藏模板、创建自定义分组、管理员可设官方分组 |

| **智能推荐** | 场景联动推荐（做场景图时推荐场景类 prompt），使用历史推荐 |

## 5. 延后到后续版本

| 功能 | 延后理由 | 计划版本 |
|------|------|:--:|
| 数字人带货视频 | 第三方 API 成本高、稳定性待验证 | V2 |
| 小红书/抖音/FB/Ins 种草文案 | 核心文案生成未验证市场反馈 | V2 |
| 大促活动海报配图 | 依赖基础功能跑通 | V2 |
| 虾币虚拟货币收费 | 当前先验证产品价值，收费体系延后 | V3 |
| 平台直推插件 | 需要各平台 API 授权，复杂度高 | V3 |
| 场景模板市场 | 用户量不够时没网络效应 | V3 |
| 转化率追踪 | 需要部署追踪代码，卖家使用门槛高 | V3 |
| 第三方 API 代理 | 偏离图片/视频/文案核心 | 暂不规划 |
| 浏览器自动化（店铺运营） | 另一产品赛道 | 暂不规划 |
| 虚拟试穿/换色/换脸等进阶图片 | 基础图片功能先用起来 | V2 |

## 6. 用户主流程

```
登录/注册
  → 工作台首页（用量统计 + 功能入口）
  → 选择功能：图片生成 / 文案生成 / 视频生成 / DIY页面
  → 图片流程：上传 → 选平台尺寸 → 选场景/风格 → AI生成 → 预览对比 → 下载
  → 文案流程：输入商品信息 → 选平台 → 选文案类型 → AI生成 → 复制/编辑
  → 视频流程：上传图片 → 选模板/脚本 → AI生成 → 预览 → 下载
  → DIY页面流程：选模板 → 拖拽编辑 → 预览 → 提交审核 → 发布上线
```

## 8. 验收标准

### 图片模块
1. 抠图：上传商品图后 3 秒内完成，边缘误差 ≤2 像素
2. 白底图：支持 3 种白色 + 阴影开关 + 800/1600/原图三档尺寸
3. 场景图：≥20 个预设场景，自定义 Prompt 可描述场景，商品轮廓无变形
4. 平台适配：13 平台规格配置化存储，一键输出对应尺寸，格式/大小自动校验
5. 批量处理：≥50 张同时处理，统一参数，进度条展示，一键 ZIP 下载
6. 图片对比：并排/滑动/叠图三种模式，多风格网格排列

### 文案模块
1. 标题生成：选择平台后标题自动适配长度限制、禁用词过滤、SEO 关键词嵌入
2. 卖点文案：结构化输出（痛点→方案→优势→行动），每条卖点 15-30 字
3. 跨境翻译：9 语种，输出电商话术而非直译，文化适配正确
4. 短视频脚本：三平台差异化结构，含口播台词+镜头提示+时长标注

### 视频模块
1. 图片转视频：3-10 张图片合成 15-30 秒视频，含转场+配乐+字幕
2. 生成进度实时展示，支持取消和重试

### DIY 页面管理系统
1. 模板库 ≥20 个行业模板，运营人员选模板后 1 分钟内可开始编辑
2. 页面状态机完整闭环，状态间跳转有权限校验
3. PC/移动端独立配置，发布后自适应渲染
4. 发布前自动校验（组件合法性+敏感词+图片上传），不通过禁止发布
5. 一键上架/下架，操作日志可追溯
6. 页面访问统计（PV/UV）展示

### 拖拽可视化编辑器（运营人员验证标准）
1. 从组件库拖入组件到画布，松手即到位，无需点确认
2. 组件选中后右侧显示表单式属性面板（非 JSON），改文字、换图片、调颜色均可视化操作
3. 首次进入有 overlay 步骤引导，5 步内完成第一次页面搭建
4. 撤销/重做无限制，Ctrl+Z 即时回退
5. 30 秒自动保存，关闭浏览器再打开弹窗恢复
6. 移动端预览一键切换，组件在手机宽度下不错位

### 提示词增强
1. 模板库 ≥100 个电商预设，按品类/风格/平台可搜索
2. {{变量}} 自动高亮，弹出统一填写面板
3. 收藏/分组实时同步，管理后台可创建官方分组
