## 1. 产品概述

### 1.1 产品定位

Movio AI 是一款面向电商商家的 **AI 智能助手 SaaS 平台**，通过大语言模型 + 自定义知识库，为商家提供智能客服、商品推荐、订单查询、营销文案生成、数据分析等一站式 AI 服务，帮助商家降本增效、提升转化率。

### 1.2 核心价值主张

| 价值点 | 说明 |
|--------|------|
| **降本** | AI 替代人工客服，减少 70% 重复咨询 |
| **增效** | 自动生成营销文案/商品描述，提升运营效率 |
| **转化** | 智能推荐 + 个性化话术，提升店铺转化率 |
| **洞察** | 数据自动分析，AI 给出经营建议 |

### 1.3 产品形态

- **SaaS Web 管理后台**: 商家配置、管理、监控
- **AI 对话 Widget**: 嵌入商家店铺的智能客服组件
- **开放 API**: 供第三方系统集成调用

### 1.4 技术架构

```
前端: Nuxt3 + Vue3 + TypeScript + Pinia + Element Plus
后端: Express.js + TypeScript + Prisma ORM
存储: MySQL 8.0 + Redis 7 + MinIO
AI  : 多模型路由 (Claude/GPT/Gemini) + RAG 知识库
```

## 3. 整体业务流程

### 3.1 核心业务链路

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  商家入驻  │ →  │  店铺配置  │ →  │  知识库   │ →  │  Widget  │
│  (注册)   │    │ (基础信息) │    │  (训练)   │    │  (嵌入)   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                                      ↓
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  数据分析  │ ←  │  订单处理  │ ←  │  AI 回复  │ ←  │  用户咨询  │
│  (洞察)   │    │ (履约)    │    │  (智能)   │    │  (对话)   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 3.2 用户对话流程

```
用户发消息 → 意图识别 → 路由分发
                        ├── 商品咨询 → 知识库检索 → 商品推荐 → AI 回复
                        ├── 订单查询 → 订单服务查询 → 格式化 → AI 回复
                        ├── 售后问题 → 意图分类 → 转人工 / AI 回复
                        ├── 闲聊     → 直接 AI 回复
                        └── 未知     → 转人工客服
```

## 5. 模块一：用户中心

### M01-01 注册/登录

**描述**: 用户通过邮箱+密码注册账号，系统发送邮件验证码完成验证。

**使用场景**:
1. 新商家首次注册 Movio AI 平台
2. 已有账号商家登录管理后台
3. 店铺员工使用子账号登录

**业务规则**:
- 邮箱格式校验，不允许重复注册
- 密码长度 8-32 位，须含大小写字母+数字
- 验证码 6 位数字，有效期 10 分钟，每日限发 5 次
- 连续失败 5 次账号锁定 30 分钟
- 登录成功后签发 JWT (Access Token 2h + Refresh Token 7d)
- 新注册默认创建租户，角色为 TENANT_ADMIN

### M01-02 三方登录

**描述**: 支持 Google / GitHub / 微信 OAuth 2.0 登录。

**使用场景**: 用户不希望单独创建密码账号，使用已有的三方账号快速登录。

**业务规则**:
- 三方账号首次登录自动创建本地账号
- 三方登录后可绑定邮箱/手机号
- 支持一个账号绑定多个三方登录方式
- 解除绑定前需验证至少保留一种登录方式

### M01-03 手机验证码登录

**描述**: 使用手机号+短信验证码登录。

**使用场景**: 忘记邮箱或习惯手机号操作的用户。

**业务规则**:
- 手机号格式校验（支持国际区号）
- 短信验证码 4 位/6 位，有效期 5 分钟
- 同一手机号每日限发 10 次

### M01-04 忘记/重置密码

**描述**: 通过邮箱验证码重置密码。

**使用场景**: 用户忘记登录密码。

**业务规则**:
- 验证邮箱验证码后设置新密码
- 新密码不能与最近 3 次密码相同
- 重置成功后强制所有设备重新登录

### M01-05 个人资料管理

**描述**: 用户编辑个人基本信息。

**字段**: 头像、昵称、手机号、邮箱、个人简介、时区、语言偏好

**业务规则**: 邮箱修改需重新验证，手机号修改需短信验证。

### M01-06 账号安全设置

**描述**: 管理账号安全相关配置。

**功能**:
- 密码修改（需验证旧密码）
- MFA 二次验证（TOTP）
- 登录设备管理
- 操作通知设置

### M01-07 团队/子账号管理

**描述**: 租户管理员创建、管理团队成员的子账号。

**使用场景**: 商家店铺有多名员工需要分工操作。

**业务规则**:
- 子账号数量受套餐限制（基础版 3 个、专业版 10 个、企业版不限）
- 子账号可分配角色（STORE_OPERATOR / CUSTOMER_SERVICE）
- 子账号不可创建下级账号
- 管理员可禁用/启用/删除子账号

### M01-08 角色与权限配置

**描述**: 管理员配置角色的功能权限。

**业务规则**: SUPER_ADMIN 预设不可编辑，TENANT_ADMIN 仅可编辑本租户下自定义角色。

### M01-09 操作日志查看

**描述**: 用户查看自己账号的操作历史。

**记录内容**: 登录时间/IP、密码修改、资料修改、关键操作。

### M01-10 通知偏好设置

**描述**: 设置哪些事件需要推送通知。

**通知类型**: 邮件、站内信、短信、WebPush。

**通知事件**: 订单状态变更、AI 异常告警、系统公告、营销活动提醒。

### M01-11 会话管理

**描述**: 查看当前活跃的登录会话，支持踢出指定设备。

### M01-12 账号注销

**描述**: 用户主动注销账号。

**业务规则**:
- 需验证密码或邮箱验证码
- 注销后数据保留 30 天，期间可恢复
- 30 天后永久删除（GDPR 合规）
- 租户管理员注销将删除整个租户数据

## 6. 模块二：AI 智能对话

### M02-01 AI 对话界面

**描述**: 实时流式对话 UI，支持 Markdown 渲染、富媒体展示。

**使用场景**:
- C 端用户在店铺页面通过 Widget 咨询
- 客服人员在后台查看/监控对话
- 运营人员在后台测试 AI 回复效果

**业务规则**:
- 采用 SSE (Server-Sent Events) 实现流式输出
- 支持打字机效果逐字显示
- 支持中断生成
- 30 秒无响应自动重试

### M02-02 多轮对话上下文记忆

**描述**: AI 记住本次对话上下文，支持多轮关联问答。

**业务规则**:
- 会话上下文窗口: 最近 20 轮对话或 8000 tokens
- 会话超时 30 分钟自动归档
- 用户可主动清除上下文重新开始
- 跨会话不共享上下文

### M02-03 意图识别与路由

**描述**: 自动识别用户意图并路由到对应处理逻辑。

**意图分类**:
| 意图 | 处理策略 |
|------|----------|
| 商品咨询 | 检索知识库 → 商品匹配 → AI 回复 |
| 价格咨询 | 查询商品价格 → 对比 → AI 回复 |
| 订单查询 | 查询订单系统 → 格式化 → AI 回复 |
| 物流查询 | 查询物流接口 → AI 回复 |
| 售后投诉 | 情绪识别 → 意图分类 → 转人工/AI 安抚 |
| 闲聊 | 直接 AI 回复 |
| 未知 | 转人工客服 |

**业务规则**: 意图识别置信度 < 0.7 时降级为"未知"处理。

### M02-04 商品智能推荐

**描述**: 基于用户对话内容和行为，推荐匹配商品。

**使用场景**: 用户描述需求（如"我想买一件夏天穿的连衣裙"），AI 匹配商品推荐。

**业务规则**:
- 从知识库 + 商品库联合检索
- 推荐结果 ≤ 5 个，含商品图/价格/简短描述
- 支持"更多"翻页加载
- 推荐商品点击计入转化统计

### M02-05 订单查询与追踪

**描述**: 用户通过对话查询订单状态。

**使用场景**: "我的订单到哪了？"、"帮我查一下订单号 xxx"。

**业务规则**:
- 需用户身份验证（订单号+手机尾号 / 登录态）
- 返回订单状态、物流节点、预计送达
- 支持订阅物流更新通知

### M02-06 售后问题处理

**描述**: 处理退款、退货、换货等售后请求。

**使用场景**: "我要退货"、"收到的商品有质量问题"。

**业务规则**:
- AI 自动收集退货原因、订单号、图片凭证
- 简单售后直接生成售后单
- 复杂售后转人工客服处理
- 售后单状态同步通知用户

### M02-07 人工客服转接

**描述**: AI 无法处理时无缝转接人工客服。

**触发条件**:
- 意图置信度低
- 用户明确要求人工
- 情绪识别为"愤怒"且两次 AI 回复未解决
- 售后投诉类

**业务规则**:
- 转接时携带完整对话上下文
- 人工客服可查看 AI 分析摘要
- 支持排队等待和离线留言

### M02-08 对话历史记录

**描述**: 商家后台可查看、搜索、筛选所有对话记录。

**功能**:
- 按时间/用户/意图/满意度筛选
- 对话详情查看（完整上下文）
- 标记/标注对话
- 导出对话数据

### M02-09 对话质量评估

**描述**: 评估 AI 对话质量，持续优化效果。

**评估维度**:
- 用户满意度评分（👍/👎）
- 意图识别准确率
- 问题解决率（是否转人工）
- 平均对话轮次
- 响应时间

### M02-10 敏感词过滤

**描述**: 对话内容实时敏感词检测与过滤。

**业务规则**:
- 用户输入和 AI 输出双向过滤
- 命中敏感词可选择: 拒绝回复 / 替换为 *** / 转人工
- 敏感词命中记录日志并告警
- 支持自定义敏感词库

### M02-11 快捷回复模板

**描述**: 预设常用回复模板，人工客服可一键发送。

**业务规则**: 模板支持变量替换（用户名/订单号/商品名），TENANT_ADMIN 可自定义。

### M02-14 对话数据导出

**描述**: 导出对话数据为 CSV/JSON 格式。

### M02-15 对话 Widget 嵌入代码

**功能**: 浮动按钮+对话窗口，支持自定义颜色/位置/Logo。点击打开 Widget，记录来源页面 URL。

## 16. 非功能需求

### 16.1 性能要求

| 指标 | 目标值 |
|------|--------|
| 页面首屏加载 | ≤ 2s |
| API 响应时间 (P95) | ≤ 500ms |
| AI 首 Token 时间 | ≤ 2s |
| AI 流式生成速度 | ≥ 30 tokens/s |
| 并发对话数 | ≥ 1000 |
| 系统可用性 | ≥ 99.9% |

### 16.2 安全要求

- 全站 HTTPS
- JWT + Refresh Token 认证
- SQL 注入防护（Prisma ORM 参数化查询）
- XSS 防护（输入输出过滤）
- CSRF Token 验证
- API 限流（全局 + 用户 + 接口三层）
- 敏感数据加密存储（密码 bcrypt / 手机号 AES）
- 操作日志审计
- GDPR 合规（数据删除权 / 数据导出权）

### 16.3 可扩展性要求

- 支持水平扩展（无状态服务 + Redis 共享会话）
- 数据库读写分离支持
- AI 模型热切换
- 插件化渠道接入

### 16.4 兼容性要求

| 端 | 支持范围 |
|----|----------|
| Web 管理后台 | Chrome/Firefox/Safari/Edge 最新 2 个主版本 |
| Widget | 所有现代浏览器 + IE11 |
| 移动端 | iOS 14+ Safari / Android 8+ Chrome |

## 17. 技术约束与规范

### 17.1 开发规范

参照项目 CLAUDE.md 和存档文件中的六大类统一开发规范:
- **数据类规范**: 统一命名/字段类型/枚举值

- MySQL 8.0 InnoDB
