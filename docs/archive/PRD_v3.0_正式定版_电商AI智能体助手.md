## 第1章 产品概述

### 1.1 产品定位

| 项目 | 内容 |
|:--|:--|
| **正式名称** | 电商 AI 智能体助手 |
| **核心定位** | AI 图片处理 + AI 短视频创作 + 长视频录播智能剪辑 + AI 数字人 四大核心主线 |
| **目标用户** | 电商卖家、短视频创作者、内容运营团队、跨境电商从业者 |
| **产品形态** | PC Web 管理后台 + H5 移动端 |
| **技术栈** | Nuxt3 + Vue3 + TypeScript + Express + MySQL + Redis + MinIO |

### 1.2 四大核心主线

```
电商 AI 智能体助手
├── 主线一：AI 图片处理        → 商品图生成/编辑/批量处理/电商主图复刻
├── 主线二：AI 短视频创作      → 视频生成/爆款复刻/动作迁移/一键成片
├── 主线三：长视频录播智能剪辑  → 精剪/删减/杂音优化/字幕校对
└── 主线四：AI 数字人          → 口播数字人/面容翻译/语音翻译
```

### 1.3 明确砍掉范围（暂不开发）

以下功能**本次不纳入开发计划**，后续版本迭代再评估：
- 店铺商品迁移
- 商品跨平台搬家
- 库存价格同步
- 多平台商品上下架
- 选品分析
- 会员付费套餐
- 额度管控/算力计费

## 第3章 视频核心模块（M01 — 22 项功能）

### 3.1 视频生成

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 用户输入文字 Prompt 或上传参考素材，AI 生成完整短视频 |
| **输入** | 文字描述 / 参考图片 / 参考视频 / 风格选择 |
| **输出** | 完整短视频（默认 15s 竖屏，时长可调） |
| **使用场景** | 无素材从零创作、创意发散、快速出片 |
| **业务规则** | 支持多模型引擎调度（Seedance / 即梦 / Kling / Wan）；默认高清输出；失败自动重试 |
| **优先级** | P0 |

### 3.2 视频提示词润色

| 属性 | 内容 |
|:--|:--|
| **功能描述** | AI 自动优化用户输入的粗糙提示词，补充镜头语言、光影、风格细节 |
| **输入** | 用户原始提示词 |
| **输出** | 润色后的结构化提示词（可手动再编辑） |
| **使用场景** | 用户不熟悉提示词写法、想快速获得更好的生成效果 |
| **业务规则** | 保留原意基础上增强；支持一键套用/回退；可指定润色方向（营销/文艺/简洁） |
| **优先级** | P1 |

### 3.3 爆款视频分析

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 上传对标爆款视频 → AI 结构化分析其节奏、色调、运镜、转场、时长分布 |
| **输入** | 爆款视频文件/链接 |
| **输出** | 分析报告：镜头节奏图谱 / 色调方案 / 运镜清单 / 转场类型 / 时长分布曲线 |
| **使用场景** | 竞品拆解、学习爆款套路、指导自家视频制作 |
| **业务规则** | 分析维度：镜头分段 / BGM 节拍 / 文案节奏 / 画面色调 / 转场方式；输出可视化报告+结构化数据 |
| **优先级** | P1 |

### 3.4 爆款视频复刻生成

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 用爆款分析模板替换自家产品素材 → AI 重新生成同风格视频 |
| **输入** | 爆款分析模板 + 自家产品素材（图片/视频片段） |
| **输出** | 复刻视频（保留原爆款节奏结构，替换为自有内容） |
| **使用场景** | 批量仿制爆款结构、快速生产同风格带货视频 |
| **业务规则** | 复刻还原度 ≥ 80%；支持多产品批量复刻；保留原模板可复用 |
| **优先级** | P1 |

### 3.5 视频分镜生成器

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 输入产品卖点/文案 → AI 自动生成专业分镜脚本（含拍摄画面描述+时长+运镜建议） |
| **输入** | 产品信息 / 卖点文案 / 目标风格 |
| **输出** | 分镜脚本表：每镜画面描述 / 时长 / 运镜方式 / 字幕建议 |
| **使用场景** | 短视频拍摄前规划、团队沟通拍摄方案、新手照着拍 |
| **业务规则** | 分镜数量可指定（3-15镜）；支持导出 PDF/图片；每镜含构图参考 |
| **优先级** | P2 |

### 3.6 商品广告一键成片

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 上传商品图+卖点 → AI 自动编排生成完整商品广告视频 |
| **输入** | 商品图片（1-10张）+ 卖点文案 |
| **输出** | 15s/30s 完整商品广告视频，含转场/BGM/字幕/营销标签 |
| **使用场景** | 电商卖家快速出商品广告视频、投放信息流广告 |
| **业务规则** | 一步操作完成；自动配 BGM + 字幕 + 营销贴纸；支持多尺寸输出（9:16 / 16:9 / 1:1） |
| **优先级** | P1 |

### 3.7 单图生视频

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 1 张静态商品图 → AI 生成动态短视频 |
| **输入** | 1 张商品/人物/场景图片 |
| **输出** | 动态短视频（默认 15s 竖屏），商品展示/人物动态/场景运镜 |
| **使用场景** | 只有静态图缺视频素材、快速将商品图转为动态展示 |
| **业务规则** | Seedance 引擎（物理准确）为主力；可选时长 10s/15s/30s；画质高清/快速双模式 |
| **优先级** | P0 |

### 3.8 多图合成视频

| 属性 | 内容 |
|:--|:--|
| **功能描述** | N 张图片自动剪辑合成一条连贯带货视频 |
| **输入** | 多张商品图/场景图/细节图 |
| **输出** | 智能转场+自然运镜+连贯成片（15s/30s） |
| **使用场景** | 多张商品图要做成展示视频、产品合辑快剪 |
| **业务规则** | 支持指定产品卖点 → AI 编排镜头顺序；自动匹配转场+BGM |
| **优先级** | P0 |

### 3.9 视频自动包装

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 为生成的视频自动添加字幕/BGM/营销贴纸/品牌角标/比例适配 |
| **输入** | 原始视频 + 包装配置（字幕开关/BGM选择/贴纸/Logo） |
| **输出** | 包装后的成品视频 |
| **使用场景** | 生成视频后快速加上专业包装，无需跳转其他工具 |
| **业务规则** | 智能字幕生成（Whisper 多语种）；无版权 BGM 素材库；电商营销贴纸/促销标签；品牌 Logo 角标位置可调；自动适配 9:16/1:1/16:9；支持后编辑（换BGM/改字幕/调速/换贴纸） |
| **优先级** | P1 |

### 3.10 动作迁移

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 将动作视频中的动作迁移到目标人物/角色图片上，生成新视频 |
| **输入** | 动作源视频 + 目标人物图片 |
| **输出** | 目标人物执行相同动作的新视频 |
| **使用场景** | 服装模特走秀、虚拟IP动作复用、减少重复拍摄 |
| **业务规则** | 支持 MagicAnimate + AnimateAnyone + LivePortrait 多引擎；高清 2K / 快速降帧双模式；无需提示词无抽卡，成功率 ≥ 95% |
| **优先级** | P1 |

### 3.11 批量动作迁移

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 1 条动作视频 + N 张人物/商品图 → 批量生成 N 条动作迁移视频 |
| **输入** | 1 条动作源视频 + N 张目标图片 |
| **输出** | N 条不同目标人物的动作迁移视频 |
| **使用场景** | 1 个模特走秀视频 → 100 件衣服各生成展示视频；批量生产带货视频 |
| **业务规则** | 操作 4 步：准备素材 → 启动 → 建任务 → 等待导出；单机日产千条、集群日产万条；异步队列 + WebSocket 实时进度推送 |
| **优先级** | P1 |

### 3.12 角色人物替换

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 将视频中的人物替换为另一个角色形象（真人/虚拟人/IP 形象） |
| **输入** | 原视频 + 目标角色图片 |
| **输出** | 角色替换后的新视频 |
| **使用场景** | 虚拟 IP 替代真人出镜、跨地区替换不同肤色模特、避免肖像权问题 |
| **业务规则** | 保持原视频动作/背景不变；支持真人→真人、真人→虚拟人、虚拟人→真人三种模式 |
| **优先级** | P2 |

### 3.13 视频语音翻译

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 将视频中的语音翻译为目标语言，生成新语音并合成回视频 |
| **输入** | 原视频 + 目标语言 |
| **输出** | 语音替换为新语言的新视频 |
| **使用场景** | 跨境电商视频多语言本地化、一条视频覆盖多语种市场 |
| **业务规则** | 支持中/英/日/韩/西/葡/法/德/俄/泰/越/阿等语种；保留原语调情绪；TTS 语音合成 |
| **优先级** | P2 |

### 3.14 视频字幕翻译

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 提取视频字幕并翻译为目标语言，叠加新字幕 |
| **输入** | 原视频 + 目标语言 |
| **输出** | 新语言字幕覆盖的视频 |
| **使用场景** | 跨境内容分发、多语言字幕版本 |
| **业务规则** | 先 ASR 识别原字幕 → AI 翻译 → 重新渲染字幕（保留样式）；支持双语字幕叠放 |
| **优先级** | P2 |

### 3.15 视频面容翻译

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 将视频中人物口型同步翻译为新语言，面部口型与翻译后语音匹配 |
| **输入** | 原视频 + 目标语言 |
| **输出** | 口型匹配翻译语言的新视频 |
| **使用场景** | 数字人/真人出镜视频跨国分发，口型语言同步 |
| **业务规则** | MuseTalk 口型同步 + LivePortrait 面部驱动；与语音翻译联动 |
| **优先级** | P2 |

### 3.16 口播数字人

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 选择数字人形象 + 输入口播文案 → AI 生成数字人口播视频 |
| **输入** | 口播文案 + 数字人形象选择 + 背景/手势配置 |
| **输出** | 数字人出镜讲解的完整口播视频 |
| **使用场景** | 无需真人出镜的口播带货、产品讲解、知识科普 |
| **业务规则** | 多语种 TTS 智能配音；MuseTalk 口型同步；可选数字人形象库（真人/虚拟）；支持手势/背景/服装配置；文案可编辑后重生成 |
| **优先级** | P1 |

### 3.17 长视频录播智能精剪

| 属性 | 内容 |
|:--|:--|
| **功能描述** | 上传长录播视频 → AI 自动识别高光片段、去除冗余、生成精剪版 |

### 3.20 长视频自动字幕校对

| 属性 | 内容 |

| 数据库访问 | 所有 SQL 必须在 DAO 层，Controller/Service 不得内联 SQL |
| 参数校验 | 所有 API 入参 Zod schema 校验 |
| 异步任务 | 视频/图片处理统一走 BullMQ 队列，不阻塞主线程 |
| 文件格式 | 图片默认 WebP，视频默认 H.265，保留原格式导出选项 |

### 11.2 性能基线

| 指标 | 目标值 |
|:--|:--|
| API 响应 P50 | ≤ 200ms |
| 图片生成（单张） | ≤ 10s |
| 视频生成（15s） | ≤ 3min |
| 并发任务数 | ≥ 100 |
| 文件上传限制 | 图片 20MB / 视频 500MB |
