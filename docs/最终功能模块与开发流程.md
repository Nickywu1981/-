## 技术架构

```
前端：Nuxt3 + Vue3 + TypeScript + SSR
     ├── 移动端优先 + 全站响应式
     ├── Pinia 状态管理
     ├── WebSocket 实时通信
     └── 腾讯云CDN + COS SDK

后端：Node.js + Express + CommonJS
     ├── JWT 认证 + Redis Session
     ├── BullMQ + Redis 任务队列
     ├── MySQL 8.0 数据持久化
     ├── Multer 文件上传中间件
     └── Cluster 多进程集群

AI引擎：
├── 抠图：RMBG-2.0 + SAM2 + matting级联
├── 场景：IC-Light v2 + ControlNet + 自研融合层
├── 精修：Real-ESRGAN + CV + 自研Pipeline
├── 视频：Seedance 2.0 + 即梦 + Kling + Wan 四引擎
├── 数字人：MuseTalk + LivePortrait + TTS
├── 动作迁移：MagicAnimate + AnimateAnyone+ LivePortrait
└── LLM：文案/脚本/翻译

基础设施：
```
