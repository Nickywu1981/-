## 二、模块功能需求

### 2.1 图片模块（7 项功能）

| # | 功能 | 需求细节 | 验收标准 |
|:--:|------|------|------|
| 1 | **AI 智能抠图** | 上传商品图 → 3秒完成主体识别与背景去除，头发级精细分割 | 边缘误差 ≤2px，输出透明背景 PNG |
| 2 | **AI 白底图** | 纯白/象牙白/冷白 3 种背景，可选阴影/倒影效果，800/1600/原图三档输出 | 背景色值偏差 ≤5%，阴影自然不突兀 |
| 3 | **AI 场景图生成** | 20+ 预设场景（客厅/海滩/办公桌等）+ 自定义 Prompt 描述场景，商品融入无变形 | 商品轮廓不变形，光影方向一致 |
| 4 | **AI 电商主图生成** | 基于平台规范自动生成标准主图，适配尺寸/格式/白底 | 平台合规校验全通过 |
| 5 | **13 平台尺寸适配** | 淘宝/京东/拼多多/抖音/Amazon/Shopee/Lazada/TikTok Shop/小红书/快手/视频号/eBay/Wish 主图+详情图尺寸，一键批量适配 | 44 条预设尺寸，一键裁剪为对应尺寸 |
| 6 | **批量处理** | 一次上传 ≤50 张，统一参数（抠图+白底+尺寸），进度条展示，一键导出 ZIP | 50 张 ≤10 分钟完成 |
| 7 | **图片对比/AB 测试** | 并排对比/滑动对比/叠图对比 3 模式，多风格网格排列 | 3 种模式均可切换，原图与生成图差异可视化 |

### 2.2 文案模块（4 项功能）

| # | 功能 | 需求细节 | 验收标准 |
|:--:|------|------|------|
| 1 | **商品标题生成** | 选择平台 → 输入商品关键词 → AI 生成适配标题（自动适配长度限制/禁用词过滤/SEO 关键词嵌入） | 标题长度合规、禁用词已过滤、SEO 关键词≥3个 |
| 2 | **卖点文案生成** | 输入商品信息 → AI 生成结构化文案（痛点→解决方案→产品优势→行动号召），每条 15-30 字 | FAB 结构完整、每条独立可用 |
| 3 | **跨境翻译+本地化** | 9 语种：英语/日语/韩语/泰语/印尼语/越南语/西班牙语/法语/阿拉伯语，电商话术本地化（非直译） | 文化适配正确，搜索习惯匹配各站 local |
| 4 | **短视频脚本生成** | 抖音/视频号/TikTok 三平台差异化口播脚本（开头钩子→痛点→产品展示→成交主张→引导关注），含口播台词+镜头提示+时长 | 三平台脚本结构差异明显，镜头提示具体可拍摄 |

### 2.3 视频模块（4 项功能）

| # | 功能 | 需求细节 | 验收标准 |
|:--:|------|------|------|

## 七、用户与权限体系

| 功能 | 需求细节 |
|------|------|
| **注册/登录** | 邮箱注册 + 手机号注册 + OAuth 第三方登录 |
| **JWT 认证** | Access Token（15min）+ Refresh Token（7天），登出加入黑名单立即失效 |
| **RBAC 角色** | 超级管理员 → 管理员 → 编辑者 → 普通用户 四层角色 |
| **多租户隔离** | 用户 A 无法访问用户 B 的数据（图片/素材/DIY页面/表单） |
| **CSRF 防护** | 非白名单 Origin 返回 403，敏感操作需 CSRF Token |
| **限流防护** | 单 IP 200次/分钟，超限返回 429 |
| **文件上传安全** | 仅允许 jpg/png/webp/gif/mp4，最大 10MB |
| **忘记密码** | 邮箱验证码重置 |
| **个人中心** | 修改密码/修改昵称/安全设置/用量查询 |
