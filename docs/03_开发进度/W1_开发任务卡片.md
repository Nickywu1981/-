## G4 前端开发 — 10 项

### T-G4-001 用户注册页面

| 字段 | 内容 |
|:--|:--|
| **页面** | `pages/auth/register.vue` |
| **输入** | 手机号/邮箱、密码、确认密码、邀请码(选填) |
| **输出** | 注册成功 → 自动登录 → 跳转工作台 |
| **验收** | ① 手机号格式校验 ② 密码强度校验 ③ 邀请码联级注册 |
| **配置化** | 页面标题/按钮文案/协议文案 从 `sys_config` 读取 |

## G5 后端开发 — 10 项

### T-G5-001 Auth Service 注册/登录/密码重置

| 字段 | 内容 |
|:--|:--|
| **文件** | `service/auth.service.ts` + `controller/auth.controller.ts` |
| **接口** | `POST /api/auth/register` `POST /api/auth/login` `POST /api/auth/reset-password` |
| **安全** | 密码 bcrypt 加盐、手机号/邮箱 AES-256 加密、JWT 7天过期 |
| **分销** | 注册时携带邀请码 → `distributor_relation` 自动绑定上下级 |

### T-G5-002 Config Service 配置中心

| 字段 | 内容 |
|:--|:--|
| **文件** | `service/config.service.ts` + `controller/config.controller.ts` + `controller/admin/config.controller.ts` |
| **接口** | `GET /api/config/:group` (三级权限) `POST /api/admin/config` (写入) |
| **功能** | 分组管理、key-value 编辑、变更日志记录、一键回滚 |
| **缓存** | Redis 缓存 → 写入时刷新缓存并发布版本号 |

### T-G5-003 Config SSE 版本推送 ★v4.1

| 字段 | 内容 |
|:--|:--|
| **文件** | `service/config-version.service.ts` |
| **接口** | `GET /api/config/version/stream` (SSE) |
| **功能** | 配置修改后推送 `{ version: N }` 到所有连接客户端 |

### T-G5-004 File Upload Service 文件上传

| 字段 | 内容 |
|:--|:--|
| **文件** | `utils/file-upload.ts` + `controller/upload.controller.ts` |
| **接口** | `POST /api/upload/init` `POST /api/upload/chunk` `POST /api/upload/complete` |
| **功能** | 初始化上传 → 分片接收(5MB/片) → 合并 → 上传 OSS/CDN |
| **断点** | 记录已接收分片 hash，前端轮询已上传分片后只传缺失 |

### T-G5-005 Moderation Service 内容风控 ★v4.1

| 字段 | 内容 |
|:--|:--|
| **文件** | `service/moderation.service.ts` + `middleware/content-moderation.middleware.ts` |
| **接口** | `POST /api/moderation/check` |
| **审核** | 文本: 通义千问 moderation API、图片: 阿里云绿网、视频: 截图帧+图片审核 |
| **记录** | 每次审核写入 `content_audit_log` |

### T-G5-006 中间件链完整搭建

| 字段 | 内容 |
|:--|:--|
| **文件** | `middleware/auth.middleware.ts` + `role.middleware.ts` + `content-moderation.middleware.ts` + `rate-limit.middleware.ts` + `audit-log.middleware.ts` |
| **顺序** | auth → role → content-moderation → rate-limit → audit-log |
| **限流** | 免费用户 60次/分钟、付费用户 300次/分钟 |

### T-G5-007 User & Role Controller

| 字段 | 内容 |
|:--|:--|
| **接口** | `GET /api/user/profile` `PUT /api/user/profile` `GET /api/admin/users` |
| **功能** | 用户信息、角色管理(admin)、用户列表(admin) |

### T-G5-008 Model Router Service 模型调度中台

| 字段 | 内容 |
|:--|:--|
| **文件** | `service/model-router.service.ts` + `utils/ai-caller.ts` + `utils/circuit-breaker.ts` |
| **模式** | 单一/混合/自定义三种调度模式 |
| **熔断** | 连续失败 5 次 → 踢出 60s → 半开试探 ★v4.1 |
| **降级** | 主模型不可用 → 自动切备用 → 返回降级提示 |

### T-G5-009 Job Queue Service 异步任务队列

| 字段 | 内容 |
|:--|:--|
| **文件** | `service/job-queue.service.ts` |
| **功能** | 任务提交 → Worker 消费 → 进度更新 → 结果写入 |
| **接口** | `GET /api/job/:id/status` `GET /api/job/list` |
| **重试** | 失败自动重试 max 3 次，3次后标记 failed ★v4.1 |

### T-G5-010 外部依赖确认清单调查 ★v4.1

| 字段 | 内容 |
|:--|:--|
| **交付** | 10项外部依赖逐项核实并输出调查报告 |
| **重点** | 剪映API能力确认、Seedance/通义/千问配额价格、OAuth申请流程 |

### T-G6-001 m001_core.sql — 核心表建表脚本

### T-G6-004 seed-validator 校验脚本 ★v4.1

|:--|:--|

### T-G6-005 迁移脚本版本管理
