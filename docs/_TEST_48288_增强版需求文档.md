## 第1章 项目概述与愿景

### 核心主题
Movio AI 定位为电商全平台 AI 视觉 SaaS，覆盖商家后台 + H5 移动端 + PWA + 开放 API，服务电商运营"最后一公里"的素材生成与处理需求。

### 关键要点
1. **效率提升**：传统工具需手动切换多平台、单次操作 20-60 分钟；Movio AI 一站式降低到 1-8 分钟，平均提效 300%-600%
2. **用户满意度**：全章 20 节平均 4.5/5.0，ROI 回报周期 1-6 个月
3. **规模指标**：DAU 目标 5,000-46,000 人，月生成素材 10-40 万件

### 关键数据
- 运营效率提升：244%-679%
- 人力成本节省：¥6,500-¥24,000/月
- 可用性目标：99.90%-99.99%
- 月素材量：64,609-408,711 件

### 实际项目映射
- 当前 112 页面 + 36 路由 + 38 控制器 + 14 业务模块
- 已有：主页/工作台/管理后台/账户/付费全流程
- 待补齐：Electron 桌面端、开放 API 平台、PWA 离线支持

## 第2章 技术架构设计

### 核心主题
前后端完全解耦 + Nginx 统一入口 + 10 层分层架构

### 关键要点
1. **设计模式**：策略/工厂/适配器/观察者/装饰器/责任链 6 种设计模式灵活选用
2. **存储引擎**：MySQL 8.0 InnoDB（主力）+ PostgreSQL 15（候选）+ MongoDB 7.0（日志）+ Elasticsearch 8.x（搜索）
3. **消息队列**：BullMQ + Redis（主力）、AWS SQS、Kafka、RabbitMQ 可选
4. **缓存架构**：Redis Cluster，TTL 77-582 秒按场景配置
5. **性能基线**：P50≤65-189ms、P95≤228-792ms、P99≤540-1496ms、QPS≥235-721 req/s

### 架构决策（基于实际项目）

| 后端 | Express + Zod 29/36 路由 + asyncHandler 全覆盖 | ✅ |
| 数据库 | MySQL 8.4 InnoDB + 22 表 + 多租户 tenant_id | ✅ |
| 缓存 | Redis 7 + JWT 黑名单 + 限流 + RDB/AOF | ✅ |
| 队列 | BullMQ 4 Worker (image/video/batch/notification) | ✅ |
| 存储 | MinIO S3 兼容 + WebP 转换 + 预签名 URL | ✅ |
| 部署 | Docker Compose 5 服务 + PM2 + Nginx | ✅ |
| 监控 | Prometheus 指标 + Grafana 仪表盘 + Winston 日志 | ✅ |

## 第3章 用户系统

### 核心主题
多方式认证 + 双 Token 机制 + RBAC 权限 + 多租户隔离

### 关键要点
1. **认证方式**：账号密码 + 短信验证码 + 邮箱验证码，JWT Access Token(15min) + Refresh Token(7d)
2. **安全体系**：BCrypt 密码哈希 + JWT 黑名单(Redis) + 接口限流 + IP 防刷 + CSRF Token
3. **RBAC 权限**：租户→角色→接口细粒度控制，admin/rbac/user 三级
4. **租户隔离**：tenantPool 自动注入 tenant_id，25 个 DAO 全部参数化查询

### 关键数据
- 认证端点：10 个（register/login/refresh/logout/verify-code/forgot-password/reset-password/profile/password）
- 所有认证端点 Zod schema 校验
- Rate limiting：认证端点 10req/min，验证码 3req/min

## 第12章 合规与安全

### 核心主题
全链路安全闭环：传输 → 认证 → 入参 → 数据库 → 文件 → 输出

2. **认证安全**：JWT 双 Token + 黑名单 + RBAC + 登录限流 + 账号锁定
3. **入参安全**：Zod 29/36 路由校验 + 非法字符过滤 + XSS/SQL 注入防护
4. **数据安全**：多租户行级隔离 + 参数化查询 + 敏感字段加密
5. **文件安全**：类型白名单 + 大小限制 + 病毒扫描 + 权限隔离
6. **输出安全**：CSP 安全头 + CSRF Token + CORS 白名单

### 13 平台合规
- 淘宝违禁词库 / 亚马逊图片规范 / 各平台差异化规则
