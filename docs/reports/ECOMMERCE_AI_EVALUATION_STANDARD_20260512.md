## 第一部分：电商 AI 能力测评标准（8 维度）

---

### 维度一：超长上下文记忆与业务规则留存

**测评定义：** 考察模型在多轮对话、超长文档场景下，对电商全功能模块、菜单分类、业务规则的记忆完整度和前后逻辑连贯性。

**电商场景用途：**

| 场景 | 具体要求 |
|------|------|
| 全功能模块记忆 | 能记住账号权限、渠道管理、客户管理、财务分润、推广分销、商品订单、数据报表、基础配置 8 大模块的全部功能点，跨对话不遗漏 |
| 菜单分级记忆 | 能记住 4 级菜单树结构（总后台 > 企业代理端 > 网关中台 > 用户端），每级菜单项及对应路由不混淆 |
| 业务规则留存 | 能记住"代理端手动提现 + 企业端自动结算"的分账规则、代理等级分润比例、Token 计费单价等关键业务约束 |
| 超长 PRD 承接 | 10 万+ 字需求文档输入后，能完整复述全部功能点、优先级、依赖关系，不遗漏、不跑偏 |
| 跨会话继承 | 上次会话确定的架构方案、命名约定、接口规范，下次会话直接引用，无需重复确认 |

**评分标准：**

| 分数 | 标准 |
|:----:|------|
| 9-10 | 10 万+ 字文档零遗漏，8 模块全量记忆，跨会话无缝继承 |
| 7-8 | 核心模块记忆完整，偶有细节遗漏但可快速补全 |
| 5-6 | 主要模块可记，但细节常需重复确认 |
| 3-4 | 短文档可处理，长文档明显遗忘 |
| 1-2 | 仅当前轮次记忆，超长上下文跑偏严重 |

**测评定义：** 考察模型对电商图片/视频/内容创作等细分领域的术语、流程、痛点的理解深度。

**电商场景用途：**

| 细分领域 | 具体要求 |
|------|------|
| 商品图类目 | 懂主图、白底图、详情长图、场景图、商品渲染图、幽灵模特图的区别与生成逻辑 |
| 抖音/TikTok 带货 | 懂直播切片、爆款复刻、短视频带货内容创作玩法、DOU+ 投放逻辑 |
| 视频动作迁移 | 懂"复刻原动作 → 换人 → 换背景 → 保留/更换 BGM"的完整管线 |
| 批量生产能力 | 懂"一套模板 → 批量生成 N 张详情图 / N 条同款视频"的工业化生产流程 |
| 电商 SaaS 功能 | 懂多租户、代理分润、Token 计费、AI 额度管控等 B2B 平台刚需 |

**评分标准：**

| 分数 | 标准 |
|:----:|------|
| 9-10 | 精通电商全类目术语，能主动提出行业最佳实践 |
| 7-8 | 理解主流电商场景，对细分领域能快速学习 |
| 5-6 | 了解电商基础概念，垂直深度不足 |
| 3-4 | 仅通用认知，无法区分"详情长图"和"场景图" |
| 1-2 | 电商领域基本陌生 |

### 维度三：逻辑推理与功能分类

**测评定义：** 考察模型自动对功能进行多维度分类、优先级排序、模块拆分、菜单权限梳理的能力。

**电商场景用途：**

| 场景 | 具体要求 |
|------|------|
| 三域分类 | 自动将功能划分为"电商专用 / 内容创作专用 / 双场景通用"三类 |
| 三级优先级 | 自动标注"常用主推 / 次要辅助 / 不常用可隐藏"，指导菜单默认展开/折叠 |
| 模块拆分 | 将"电商详情图"拆为：模板管理 → 批量生成 → 批量编辑 → 尺寸适配 → 导出，层次清晰 |
| 权限菜单 | 按 C 端用户 / 企业代理 / 总后台三级，梳理各自的菜单可见性和操作权限 |
| 业务规则推演 | 给定"代理佣金 = 销售额 × 等级分润比例"，能推演出 3 级代理的分润计算表 |

**评分标准：**

| 分数 | 标准 |
|:----:|------|
| 9-10 | 自动分类准确率 >95%，三级优先级无需人工调整 |
| 7-8 | 分类基本准确，偶有边界功能需人工确认 |
| 5-6 | 能分类但粒度不够，需较多人工干预 |
| 3-4 | 仅能做简单二分，多维度分类混乱 |
| 1-2 | 无法独立完成功能分类 |

### 维度四：精准指令跟随

**测评定义：** 考察模型严格按指定格式、约束条件执行的能力，不擅自增删、不改规则。

**电商场景用途：**

| 场景 | 具体要求 |
|------|------|
| 表格输出 | 按指定列（功能名称/优先级/所属模块/适用端/依赖）输出功能清单 |
| 分级清单 | 按"一级模块 → 二级功能 → 三级按钮"的层级输出，不跳级、不混级 |
| JSON 接口文档 | 按 `{ method, path, params, response, auth }` 模板输出，字段完整 |
| 格式约束遵守 | 指定 Markdown 表格就输出 Markdown，指定 JSON 就输出合法 JSON |
| 业务约束遵守 | 给定"代理端有提现、企业端无提现"，不在企业端文档中出现提现功能 |

**评分标准：**

| 分数 | 标准 |
|:----:|------|
| 9-10 | 100% 格式正确，零擅自增删，业务约束全部遵守 |
| 7-8 | 格式正确率 >95%，偶有格式细节偏差 |
| 5-6 | 主体正确，但格式有 2-3 处错误需手动修正 |
| 3-4 | 格式经常偏离，需多次纠正 |
| 1-2 | 无法稳定按指定格式输出 |
